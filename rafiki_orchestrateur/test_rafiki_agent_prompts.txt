# Tests Rafiki Agent <-> Corps Wokwi

Prérequis:
- Ouvrir le projet Wokwi du corps Rafiki.
- Lancer la simulation.
- Attendre que l'écran OLED affiche "Rafiki pret".
- Vérifier que Wokwi et Python utilisent les topics MQTT isolés:
  rafiki/468994098570147841/body/cmd
  rafiki/468994098570147841/body/status
- Depuis PowerShell, être dans le dossier:
  C:\Users\ODC\Desktop\Didier\Rafiki\rafiki_orchestrateur

Commandes utiles:

1. Tester seulement le corps Wokwi sans LLM:
python test_body_mcp_direct.py

Résultat attendu:
- "Corps Rafiki détecté."
- device = rafiki_body_wokwi
- wifi_connected = True
- mqtt_connected = True

2. Lancer l'agent en mode conversation:
python rafiki_agent.py --debug

3. Tester une seule phrase avec debug:
python rafiki_agent.py --once "Rafiki, salue l'enfant avec ton écran et ton bras." --debug


Prompts de test agent + corps Wokwi:

TEST 1 - Statut du corps
Vérifie si ton corps Wokwi est connecté.

Attendu:
- outil: rafiki_body_status ou rafiki_wait_for_body
- réponse finale: indique que le corps Wokwi est détecté si MQTT répond.


TEST 2 - Salutation écran + bras
Rafiki, salue l'enfant avec ton écran et ton bras.

Attendu:
- outil: rafiki_salute_child
- Wokwi: écran "Bonjour !" + geste du bras.


TEST 3 - Réflexion
Rafiki, montre que tu réfléchis avant de répondre.

Attendu:
- outil: rafiki_think
- Wokwi: visage thinking + geste de réflexion.


TEST 4 - Félicitation
L'enfant a donné la bonne réponse. Félicite-le avec ton écran et tes mouvements.

Attendu:
- outil: rafiki_celebrate ou rafiki_react_to_child_result avec correct=True
- Wokwi: expression happy + geste celebrate.


TEST 5 - Encouragement après erreur
L'enfant s'est trompé. Encourage-le doucement avec ton écran et tes mouvements.

Attendu:
- outil: rafiki_react_to_child_result avec correct=False
- Wokwi: expression thinking + geste thinking.


TEST 6 - Alerte
Rafiki, affiche une alerte importante et fais un geste d'alerte.

Attendu:
- outil: rafiki_alert
- Wokwi: écran alert/SOS + mouvement d'alerte.


TEST 7 - Pose directe
Mets ta tête à 70 degrés, le bras gauche à 120 degrés et le bras droit à 60 degrés.

Attendu:
- outil: rafiki_set_pose
- Wokwi: servos aux angles demandés.


TEST 8 - Démonstration complète
Rafiki, fais une démonstration complète de ton corps Wokwi.

Attendu:
- outil: rafiki_body_demo
- Wokwi: salut, réflexion, célébration, retour neutre.
